**Role**

Act as a professional UI/UX Designer and Frontend Developer who specializes in modern, clean, responsive, and user-friendly website design.

**Goal**

Analyze and improve the visual appearance of my existing website to make it look more modern, professional, attractive, and consistent while maintaining its original purpose and functionality.

**Requirements**

1. Analyze the existing website before making any changes.
2. Improve the layout, spacing, typography, color palette, visual hierarchy, buttons, cards, navigation, and footer.
3. Make the hero section more engaging and ensure the main content is easy to understand.
4. Create a consistent design system across all pages.
5. Ensure the website looks polished on desktop, tablet, and mobile devices.
6. Improve accessibility, readability, and user experience.
7. Make the design feel intentional and professionally crafted rather than generic or overly AI-generated.
8. Implement the improvements directly in the existing project.

**Constraints**

- Preserve the existing project structure, framework, and technology stack.
- Do not rebuild the entire project from scratch.
- Do not remove existing features or change the core business logic.
- Avoid excessive animations, unnecessary gradients, cluttered layouts, and decorative elements that reduce usability.
- Do not introduce unnecessary dependencies.
- Preserve the existing brand identity unless a change is genuinely needed.
- Do not modify backend logic or database structures unless absolutely necessary.
- Keep the code clean, maintainable, and consistent with the existing project.

**Validation**

After implementing the changes:

1. Run the website and inspect the actual result in the browser.
2. Check the layout on desktop and mobile.
3. Verify that buttons, links, navigation, and existing interactions still work.
4. Check the browser console for errors.
5. Run Chrome DevTools Lighthouse to evaluate Performance, Accessibility, Best Practices, and SEO.
6. Identify and fix any regressions introduced by the changes.
7. Report the improvements made, any remaining issues, and the validation results.

**Final Instruction**

First, inspect the existing project and identify its main design weaknesses. Then implement the improvements directly in the code. Do not stop at providing suggestions or sample code. Validate the actual result before declaring the task complete.

The goal is not simply to make the website look beautiful, but to create a better balance between visual quality, usability, accessibility, and performance.
